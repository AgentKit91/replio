# Replio Codex Handoff Pack v1.0

This pack translates the founder's 136-decision Replio register into an actionable product/engineering specification for Codex.

## Use

Place the files at the root of the Replio GitHub repository. `AGENTS.md` is the standing Codex instruction file. Then give Codex the task in `START_HERE_CODEX.md`.

## What is authoritative

See `docs/00_SOURCE_AUTHORITY.md`. The canonical decision register always outranks old brainstorming examples.

## Build objective

A production-ready creator-first MVP where a user connects Gmail, labels a commercial thread `Replio`, receives a Deal Workspace and commercial analysis, edits/sends a reply through Gmail, continues the negotiation, and completes the Deal — plus an operational Founder OS with strict privacy boundaries.

- `AGENTS.md` — permanent Codex behaviour/rules.
- `START_HERE_CODEX.md` — first execution assignment.
